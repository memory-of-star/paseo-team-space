# Paseo Team Space

一个独立 Paseo 插件，以及可自部署的团队同步服务。成员主动把自己的 agent 加入团队；其他成员可以阅读进度和文字历史，从固定快照在自己本机创建独立分支。团队服务没有给原 agent 发消息、停止任务或批准工具的接口。

## 安装

把 [Agent 安装指南](docs/INSTALL.md) 发给成员的 agent。它可以在各自的 daemon 主机上安装插件、开启插件总开关，并验证 `team-space` 已运行。安装完成后，成员在侧边栏打开「团队空间」，用管理员提供的一次性邀请码加入。

当前团队服务地址为 `http://47.94.77.187:18787`。使用其他团队服务时，请填写相应的服务地址。自建服务见[部署说明](docs/SERVER.md)。

## 兼容性

插件清单声明 Paseo `>=0.15.4 <0.17.0`，已验证 0.15.4 和 0.16.0-beta.1。成员需要支持插件的 daemon 和客户端。Paseo 在 daemon 上加载插件，并向客户端提供界面。

## 使用流程

1. 打开 Paseo 侧边栏的 **团队空间**。管理员填写服务地址、名字、团队名称及创建密钥。
2. 在 **成员与设置** 生成邀请口令。每个口令 24 小时有效，只能使用一次；同事使用服务地址、自己的名字和口令加入。
3. 在 **我的 Agent** 点击 **加入团队**。这会分享当前可读取的文字历史和后续进度；也可以通过 Command Center 操作当前 agent。
4. 团队成员打开 **团队 Agent → 查看对话与分支**。该界面只读，没有原会话输入框。
5. 在「从历史创建分支」中选结束快照，再选起始轮次（默认「全部历史」）。起始用户消息和该快照末尾之间的记录都会带入。选择本机模型，点击「创建并打开我的分支」，进入新 agent 后再发送第一条消息。创建本身不发起模型对话。选中的历史保存在私有工作目录的 `team-history.json`，Paseo 会提示支持读取工作区文件的 provider 在首次回答时读取它。
6. 分支默认私有，可以像普通 agent 一样再加入团队；来源会显示在共享卡片上。
7. **移出团队** 撤销原会话的团队访问并禁止新的 fork。已经创建的独立分支保留。管理员移除成员会立即使其凭据失效，并撤回该成员的共享。

## 与已有团队共用

插件 v0.2.0 沿用团队服务协议 v1。运行 v0.1.1 和 v0.2.0 的成员可以加入同一团队、双向查看并 fork 共享会话。轮次选择与空闲分支在发起 fork 的那台 daemon 上实现，老成员可以按原流程继续使用。升级已有成员的插件时保留同一 Paseo home 和插件 ID，已有成员身份、共享记录、邀请和服务数据库继续有效。

## 同步、快照与边界

- 首版是约 3 秒发布 / 2 秒读取的近实时同步，更新延迟通常为几秒；网络和历史大小会影响实际延迟。离线超过 20 秒显示离线状态。
- 分享用户/助手文字、待办与状态通知。不会上传原生 session 文件、隐藏推理、工具调用参数/输出、图片二进制或凭据配置。用户主动写在文字消息中的内容会共享，插件不承诺自动脱敏。
- 不复制代码文件、未提交修改、运行中的进程或工具环境。分支是**历史上下文 fork**，不是 provider 原生状态的无损克隆。需要代码时，由分支 owner 自行提供自己的代码上下文。
- 当 agent 空闲、历史读取前后状态未变化、末条记录为助手回复时创建快照。运行中首次加入的会话需要等到轮次结束。保留最近 100 个可 fork 快照；旧快照已经创建的分支独立保留。打开分支表单选择快照时，插件通过 v1 接口取得完整的不可变快照，服务端为该成员保存一份私有副本；本机新分支的上下文文件只写入选中的范围。
- 历史读取最多 10,000 条、500,000 字符；fork 上下文最多 120,000 字符。超限报错，不静默截断。provider 可能另有更小的上下文限制。
- 本机保存共享选择、撤回队列及 fork 请求 ID。断网移出时立即停止发布；服务器旧副本在成功收到撤回请求前仍可读。界面会显示“正在撤回”，连接恢复后重试。
- daemon / 插件重启后，在客户端加载侧边栏或本机产生 agent 生命周期事件时恢复后台同步。没有任何客户端连接且没有 agent 事件时，不会主动建立新的 SDK 会话。
- 每个 daemon 对应一个成员身份、一个团队连接。被授权访问同一个 daemon 的本地客户端共享该身份；本插件不在 daemon 内重新隔离这些客户端。首版不支持同一 daemon 上以多个插件 runtime ID 同时安装。
- 团队服务可以读取共享内容。HTTPS 提供传输加密，使用公网 HTTP 时创建密钥、成员令牌和共享内容以明文传输。退出团队不可能抹除他人已经复制或 fork 的历史。
- 服务适用于小团队单实例。没有 SSO、账号恢复界面、分支自动合并或集群部署功能。请备份 SQLite 数据目录和本机插件状态；不要将这些文件提交到代码库。

本机状态默认在 `$PASEO_HOME/plugin-data/team-space/state.json`，权限为 `0600`；测试可用 `PASEO_TEAM_SPACE_STATE` 指定独立目录。服务只存成员 token 的 SHA-256 摘要；插件本机保存自己的 bearer token，永远不通过状态 RPC 返回给界面。
